# 🌿 e-plantShopping (Paradise Nursery)

## 📌 Project Overview
e-plantShopping is a React-based web application for an online plant store called **Paradise Nursery**.  
The application allows users to browse plants, add them to a shopping cart, manage quantities, and view total prices.

---

## 🚀 Features

- 🌱 Product listing page with available plants
- 🛒 Add items to shopping cart
- ➕ Increase product quantity
- ➖ Decrease product quantity
- ❌ Remove items from cart
- 💰 Automatic total price calculation
- 🎨 Responsive UI with styled landing page
